# 💼 Portfolio Thales Almeida

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minhas habilidades, projetos e formas de contato de maneira moderna, responsiva e profissional.

## 📸 Visão Geral

O portfólio é um site estático desenvolvido com **HTML**, **CSS** e **JavaScript**, com foco em design limpo, animações suaves e uma ótima experiência em diferentes tamanhos de tela (responsividade total).

### 🎯 Seções do site:

- **Home:** Apresentação pessoal com chamada de destaque.
- **Sobre Mim:** Informações sobre minha trajetória e perfil profissional.
- **Habilidades:** Tecnologias e ferramentas que domino.
- **Projetos:** Galeria com meus principais projetos.
- **Contato:** Formas de me encontrar nas redes sociais ou por e-mail.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com Flexbox, Grid e media queries)
- JavaScript
- AOS (Animate On Scroll)
- Google Fonts
- Devicon Icons

## 📱 Responsividade

O site é completamente responsivo, adaptando-se perfeitamente a **dispositivos mobile**, **tablets** e **desktops**, garantindo navegação fluida em todas as plataformas.
